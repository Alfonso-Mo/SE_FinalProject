# CinemaCircle
CinemaCircle is a web application for movie lovers to share their opinions on new movie releases.
This web application will use an API to show movies that are currently playing in theaters. Users will be able to view through the movies,
rate them, join discussions, and give a separate score based on whether they think the movie was worth the hype or not.

## Features
  - See movies that are currently in theaters
  - Rate movies
  - Give a 'Worth Watching" score
  - Write comments and discuss about movies with other users 
  - Create an account and log in

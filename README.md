# CinemaCircle
Software engineering final project.

## About Project
CinemaCircle is a web appliction for movie lovers to share their opinions on new movie releases.

##Features
  -See movies that are currently in theatres
  -Rate movies
  -Give a 'Worth Watching" score
  -Write comments and discuss about movies with other users 
  -Create an account and log in
